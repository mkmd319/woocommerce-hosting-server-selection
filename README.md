## 二、机房：香港还是美国

外贸建站服务器的机房位置，应该跟着客户走，而不是跟着你自己的访问体验走。欧美客户优先美国或欧洲节点，亚太客户看香港、新加坡、日本。外贸站没必要为了国内打开快，牺牲目标市场的加载速度。

香港的优势是距离近，国内访问延迟低，管理后台顺手，境外服务器不强制 ICP 备案，买完就能上线。代价是价格明显更贵，热门配置还经常售罄，看到有货得马上决定。美国节点的机器便宜、库存充足，对欧美买家和 Google 爬虫都更友好。

还有一条容易漏掉的：服务器响应时间会影响收录。有建站实操文章提到，响应时间超过 3 秒，爬虫的抓取频率会明显下降。新站本来就没什么权重，再被降频，收录周期会拖得很长。这条比“打开快一点体验好”实在得多。

国内团队要频繁登后台的情况，可以主站放目标市场，后台操作走 CDN 或者另开一台便宜的香港小机器做跳板，成本比整站搬回香港低。

## 三、配置：1核2G 到底够不够

两种常见的说法并不矛盾，场景不同：

一个普通的 B2B 展示型外贸站起步，1核2G 或 2核2G 通常够用；图片多、插件重、流量起来之后再升级。这是面向轻量展示站的判断。装了 WooCommerce、跑正式交易的站，2核4G 能扛住日均几千 IP 的访问量。后者对内存和并发的要求高一档。

实际卡住人的是内存，不是 CPU。1G 内存跑 Nginx + PHP-FPM + MySQL，再挂几个插件，很容易在并发上来时触发 OOM，表现是站点突然 502、MySQL 进程被杀。2G 是跑 WordPress 的安全线，WooCommerce 建议从 2G 起，产品多、插件多直接上 4G。

升级信号看这几条：后台打开明显变慢、MySQL 日志里出现内存不足、图片上传后前台加载拖沓、做活动时页面超时。出现任意两条就该加配置，别等到掉单才动。

## 四、线路：BGP、CN2 GIA、CMIN2 各解决什么问题

带宽数字最容易误导人。同样标称 100Mbps，普通国际线路晚高峰可能跑出几十毫秒的丢包，做了三网优化的 BGP 线路能稳定压在低延迟区间。丢包对 WordPress 的影响比带宽大得多，一个请求要重传三次，页面就白屏两秒。

有测评给出过量级参考：8核16G 的机器走绕路普通国际线路，国内用户首屏 4–5 秒；同配置走 CN2 GIA 能缩到 1.5 秒以内。这类测试的环境变量多，当参考看，别当承诺。

三条线路的分工：

- **BGP**：多线智能选路，解决国内电信、联通、移动三网访问不一致的问题。香港机房的主流做法，性价比最好。
- **CN2 GIA**：电信精品承载网，回程稳定、丢包低，价格最贵，适合自己要频繁操作后台、或者客户里有大量国内访问的场景。
- **CMIN2**：移动的国际精品线路，比 CN2 GIA 便宜，带宽给得大，适合大流量站。

以香港 BGP 线路的公开实测样本看，到东京约 53ms、新加坡约 37ms，到欧洲和北美在 170–210ms 区间。这个量级说明香港机房对亚太客户够快，对欧美客户就属于跨洲访问了。

判断规则很简单：客户在欧美，中国方向的线路优化意义有限，钱花在机房位置和带宽上更值；客户在亚太，或者你自己每天要登后台改内容，才值得为 CN2 GIA 付溢价。

## 五、下单前必须问清的四件事

这四项在套餐页上通常不显眼，却直接决定你用起来顺不顺。

**1. 续费价。** 首年折扣和续费价是两回事。有商家把“续费同价”写进条款，也有商家用循环折扣，终身按折后价续。下单前把账单周期切到年付看一眼总价，别只看首月数字。雨云的续费价以产品页当前展示为准，购买时确认一次。

**2. 流量超额怎么处理。** 限速和停机是两种体验。有的商家超额后把带宽限到 1Mbps，次月 1 日重置，站还能打开，只是慢；有的直接限到 100Mbps–1Gbps 不断线。知道这条规则，你才知道该买多大的流量档。

**3. 备份在不在套餐里。** 不少 VPS 明确不提供自动备份，数据全靠自己。外贸站的产品资料、询盘记录、客户邮件都是资产，WordPress 上装个备份插件，设成每天自动传到对象存储，这件事比多买 1G 内存重要。

**4. 换 IP 和发信。** IP 进了反垃圾邮件黑名单，能不能换、收不收费、多久能换一次，提前问清。询盘邮件发不出去是另一件高频事故：WordPress 默认用 PHP 的 mail() 发信，很多服务器禁用这个函数，或者发出去直接被判垃圾邮件。解决办法是装 SMTP 插件（WP Mail SMTP 这类），用企业邮箱的 SMTP 服务，587 端口配 TLS。有的商家 25 端口需要付保证金才开，理由是被 Spam 投诉罚过钱，这类限制在条款里才看得到。

## 七、几个常被问到的问题

**外贸站需要备案吗？** 服务器放在境外或香港，不强制 ICP 备案，买完直接部署上线，这是很多人选境外机房的直接原因。商家通常会要求注册资料真实，别用匿名网络下单。

**1G 内存能跑 WordPress 吗？** 能。Nginx + PHP + MySQL 加缓存插件，一个轻量站跑得动。插件超过十个、或者要装 WooCommerce，直接上 2G，省下来的钱不够赔一次宕机。

**装宝塔还是 1Panel？** 两个都能用，面板本身会占两三百 MB 内存，1G 的机器装面板之后剩给站点的空间不多，2G 以上再考虑。

**询盘邮件为什么收不到？** 先排查发信方式。装 SMTP 插件走 587 端口配 TLS，同时装一个表单记录插件把所有提交存在后台，邮件丢了还能从数据库里捞回来。

**原生 IP 对 SEO 有用吗？** 不直接提升排名，排名还是看内容质量和页面性能。原生 IP 的价值在于账号安全，比如支付通道和广告账户不容易被误判。
